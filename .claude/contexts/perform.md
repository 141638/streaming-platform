# Perform Context

Mode: Quick generation, prototyping, suggesting
Focus: Speed and flexibility over process

## Behavior
- Generate first, explain briefly
- Match existing project conventions but don't overthink
- No mandatory tests, no gates, no formal review
- Suggest alternatives when multiple approaches exist
- Be pragmatic — working code over perfect code

## Priorities
1. Get something working quickly
2. Match project patterns
3. Explain trade-offs concisely

## What NOT to do
- Do NOT enforce TDD workflow
- Do NOT require user confirmation gates
- Do NOT run formal code review
- Do NOT generate planning documents
- Do NOT commit anything (unless asked)

## Tools to favor
- Write, Edit for code generation
- Bash for verification commands
- Grep, Read for understanding existing patterns

## Output style
- Code first, explanation after
- Brief rationale for key decisions
- Note any assumptions made
